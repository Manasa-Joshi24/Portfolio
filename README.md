# PortfolioOS — Interactive Resume & Bio-data Website

## Pages
- `index.html` — interactive landing page
- `resume.html` — resume with timeline + skill bars + print/save-PDF button
- `biodata.html` — interactive bio-data with reveal section + rotating quotes
- `projects.html` — filterable project lab

## Technologies
- HTML5 semantic elements
- CSS3 responsive styling, animations and dark/light theme
- JavaScript
- jQuery 3.7.1

## Before submission
Replace:
- `Your Name`
- email / phone
- DOB / gender / school details
- GitHub and LinkedIn `#` links
- project links
- any percentages or achievements you want to personalise

## Cloud hosting — easiest option: GitHub Pages
1. Create a GitHub repository, e.g. `interactive-resume`.
2. Upload all files/folders exactly as they are.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a public `https://...github.io/...` website URL.

## Alternative
The same folder can be deployed on Netlify or Vercel as a static site.

## Viva points
1. HTML provides the structure and semantic content.
2. CSS provides layout, responsive design, animations and theme styling.
3. JavaScript handles theme persistence, typing animation, counters and keyboard shortcut.
4. jQuery handles click events, animations, filtering and DOM manipulation.
5. Multiple HTML pages demonstrate website navigation.
6. GitHub Pages acts as the cloud hosting platform.
